# S1 Test Suite: Binary Tree Traversals (Scheme)

## 1. How to Run the Tests

Under the assignment rules, `code/id_q3.rkt` contains only definitions and prints nothing when loaded alone. The grader evaluates functions by appending test calls to the end of the file.

### Running with Racket

#### Linux / macOS / Bash:
```bash
cat code/id_q3.rkt - <<'EOF' | racket
(define t1 '(4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))))
(print-inorder t1)
EOF
```

#### Windows (PowerShell):
```powershell
$code = Get-Content -Raw "code/id_q3.rkt"
$test = "(define t1 '(4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))))`n(print-inorder t1)"
$tmp = "code/temp_test.rkt"
Set-Content -Path $tmp -Value ($code + "`n" + $test)
racket $tmp
Remove-Item $tmp
```

## Part 1: Task S1.a (`print-inorder`) Tests

### Test 1.1: Problem Specification Canonical Example (`t1`)
- **Objective**: Verify that `print-inorder` outputs the exact inorder sequence for the balanced tree `t1` provided in the assignment description.
- **Test Code**:
  ```scheme
  (define t1
    '(4 (2 (1 () ())
           (3 () ()))
        (6 (5 () ())
           (7 () ()))))
  (print-inorder t1)
  ```
- **Expected Output**:
  ```text
  (1 2 3 4 5 6 7)
  ```

---

### Test 1.2: Specification Right-Skewed Tree (`t2`)
- **Objective**: Verify `print-inorder` on the linear right-leaning tree `t2 = (1 () (2 () (3 () ())))` from the PDF.
- **Test Code**:
  ```scheme
  (define t2 '(1 () (2 () (3 () ()))))
  (print-inorder t2)
  ```
- **Expected Output**:
  ```text
  (1 2 3)
  ```

### Test 1.10: All-In-One Automated Verification Script
- **Objective**: Validate all S1.a test cases together in a single test run.
- **Script**:
  ```scheme
  #lang racket/base
  ;; Note: Append to code/id_q3.rkt during testing

  (define (check name actual expected)
    (if (equal? actual expected)
        (begin
          (display "PASS: ")
          (display name)
          (newline))
        (begin
          (display "FAIL: ")
          (display name)
          (newline)
          (display "  Expected: ")
          (display expected)
          (newline)
          (display "  Actual:   ")
          (display actual)
          (newline))))

  (check "Test 1.1 (Canonical t1)"
         (tree-inorder '(4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))))
         '(1 2 3 4 5 6 7))

  (check "Test 1.2 (Right-skewed t2)"
         (tree-inorder '(1 () (2 () (3 () ()))))
         '(1 2 3))

  (check "Test 1.3 (Symbol tree t3)"
         (tree-inorder '(a (b () ()) (c () ())))
         '(b a c))

  (check "Test 1.4 (Empty tree)"
         (tree-inorder '())
         '())

  (check "Test 1.5 (Single node)"
         (tree-inorder '(42 () ()))
         '(42))

  (check "Test 1.6 (Left-skewed)"
         (tree-inorder '(3 (2 (1 () ()) ()) ()))
         '(1 2 3))

  (check "Test 1.7 (Zigzag)"
         (tree-inorder '(a (b () (c (d () ()) ())) (e () (f () (g () ())))))
         '(b d c a e f g))

  (check "Test 1.8 (Negatives and zero)"
         (tree-inorder '(0 (-5 (-10 () ()) ()) (5 () (10 () ()))))
         '(-10 -5 0 5 10))

  (display "\nAll print-inorder displays:\n")
  (print-inorder '(4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))))
  (print-inorder '())
  (print-inorder '(42 () ()))
  (print-inorder '(a (b () (c (d () ()) ())) (e () (f () (g () ())))))
  ```
