# S1 Test Suite: Binary Tree Traversals (Scheme)


## 1. How to Run the Tests

Under the assignment rules, `code/id_q3.rkt` contains only definitions and prints nothing when loaded alone. The grader evaluates functions by appending test calls to the end of the file.

### Running with Racket
To test locally, simulate the grader by appending calls to `id_q3.rkt` or executing via Racket:

#### Linux / macOS / Bash:
```bash
cat code/id_q3.rkt - <<'EOF' | racket
(define t1 '(4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))))
(print-inorder t1)
EOF
```

#### Windows (PowerShell):
```powershell
$code = Get-Content -Raw "code/id_q3.rkt"
$test = "(define t1 '(4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))))`n(print-inorder t1)"
$tmp = "code/temp_test.rkt"
Set-Content -Path $tmp -Value ($code + "`n" + $test)
& "C:\Program Files\Racket\racket.exe" $tmp
Remove-Item $tmp
```

## Part 1: Task S1.a (`print-inorder`) Tests

### Test 1.1: Problem Specification Canonical Example (`t1`)
- **Objective**: Verify that `print-inorder` outputs the exact inorder sequence for the balanced tree `t1` provided in the assignment description:
  $$t_1 = (4\ (2\ (1\ ()\ ())\ (3\ ()\ ()))\ (6\ (5\ ()\ ())\ (7\ ()\ ()))$$
- **Test Code**:
  ```scheme
  (define t1
    '(4 (2 (1 () ())
           (3 () ()))
        (6 (5 () ())
           (7 () ()))))
  (print-inorder t1)
  ```
- **Expected Output**:
  ```text
  (1 2 3 4 5 6 7)
  ```
- **Status**: **PASS**
