# P1 Test Suite: Department Assignment Puzzle, Reloaded

This document contains all test specifications, runnable commands, expected outputs, and edge cases for **Task P1.a (solve)**, **Task P1.b (count)**, and **Task P1.c (repair)** implemented in [code/id_q1.pl](file:///c:/Users/Vikash%20Kukreti/Downloads/Popl_assign2-main(1)/Popl_assign2-main/code/id_q1.pl).

## 1. How to Run the Tests

All tests are executed using SWI-Prolog directly from the repository root:
```bash
swipl -q -f code/id_q1.pl -g "<goal>" -t halt
```
Or from within the `code/` directory:
```bash
cd code
swipl -q -f id_q1.pl -g "<goal>" -t halt
```
