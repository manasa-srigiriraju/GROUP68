## 2. Test 1: `main/0` Output Format & Solution Validation

### Goal
Verify that `main/0` outputs exactly four lines in the required order (`Alex`, `Ben`, `Carla`, `Dana`) matching the format `<Name> = [<Dept>, <Lang>, <Project>]`, and that the derived attributes satisfy all 8 clues without hard-coding.

### Command
```bash
swipl -q -f code/id_q1.pl -g main -t halt
```

### Expected Output
```text

Ben = [development, javascript, web]
Carla = [research, c++, data]
Dana = [testing, python, embedded]
```

- Status: **PASS**


## 5. Test 4: Individual Clue Negative Unit Tests

### Goal
Verify that each `clue(N, Solution)` fails when given a fully filled-in candidate solution that intentionally violates clue $N$.

### Test Cases
1. **Clue 1 Negatives**:
   - `1a`: AI project person works in `research` (violates "does not work in research").
   - `1b`: AI project person is `'Dana'` (violates "is not Dana").
2. **Clue 2 Negatives**:
   - `2a`: Alex works in `development` (violates "does not work in development").
   - `2b`: Alex prefers `'c++'` (violates "does not prefer C++").
3. **Clue 3 Negative**:
   - `3`: The friend working in `testing` does not like `python`.
4. **Clue 4 Negatives**:
   - `4a`: Ben does not prefer `web`.
   - `4b`: Ben works in `testing` (violates "does not work in testing").
5. **Clue 5 Negative**:
   - `5`: The friend whose favorite language is `java` works in a department other than `design`.
6. **Clue 6 Negatives**:
   - `6a`: Carla prefers `embedded` (violates "project preference is not embedded").
   - `6b`: Carla works in `development` (violates "department is not development").
7. **Clue 7 Negatives**:
   - `7a`: Dana's favorite language is `java` (violates "favorite language is not Java").
   - `7b`: Dana works in `design` (violates "works in research or testing").
8. **Clue 8 Negatives**:
   - `8a`: The friend preferring `data` works in `design` (violates "works in research").
   - `8b`: The friend preferring `data` uses `javascript` (violates "does not use JavaScript").

## 6. Test 5: Exhaustive Clue Satisfaction for All Solutions

### Goal
Enumerate all assignments satisfying clues 1 through 8 and confirm that every clue holds for each solution.

### Command
```bash
swipl -q -f code/id_q1.pl -g "
findall(S, solve(S), Sols),
length(Sols, Count),
format('Total valid solutions found: ~w~n', [Count]),
forall(member(Sol, Sols), (
    forall(between(1, 8, N), clue(N, Sol))
)),
writeln('All clues verified for all solutions: PASS'),
halt.
"
```

### Expected Output
```text
Total valid solutions found: 3
All clues verified for all solutions: PASS
```

### Validation Result
- Status: **PASS**
