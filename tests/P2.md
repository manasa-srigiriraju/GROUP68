## 2. Problem Specification & Constraint Summary

- **Predicate 1**: `generate_equation(List, Equation)`
  - Unifies `Equation` with one valid equation string for `List`.
  - Any valid equation is accepted.
  - Must **fail** (not throw an exception, not loop infinitely) if no valid equation exists, including for lists of length 0 or 1.
  - On backtracking (`;`), generates subsequent valid equations.
- **Predicate 2**: `all_equations(List, Es)`
  - Unifies `Es` with the list of all distinct valid equation strings for `List`.
  - Yields `Es = []` if no valid equation exists.
- **Equation Structure**:
  - $L = R$, where $L$ is an expression over $n_1 \dots n_j$ and $R$ is an expression over $n_{j+1} \dots n_k$, with $1 \le j < k$.
  - Every number is used exactly once, in original order.
  - Exactly one `=` sign.
  - No unary minus; digits of different numbers are never concatenated.
  - Sub-expressions may evaluate to negative values.
  - **Division constraint**: Allowed only when division is exact ($A \pmod B == 0$) and divisor is non-zero ($B \ne 0$). Applies to every internal division node.
  - Value constraint: Integer evaluation of $L$ must equal $R$.
- **Canonical Parenthesization & String Output Rules**:
  - SWI-Prolog string (`string(E)` is true, not an atom or char code list).
  - No spaces. Decimal numbers.
  - Operator precedence: `*` and `/` (higher, level 2) bind tighter than `+` and `-` (lower, level 1).
  - Operators are left-associative.
  - **Left operand**: enclosed in parentheses *only if* its operator has *strictly lower precedence* than parent operator.
  - **Right operand**: enclosed in parentheses *if* its operator has *lower or equal precedence* to parent operator.
  - Single numbers are never parenthesized.
  - Every distinct expression tree maps to a unique canonical string (e.g., `1+(2+3)` vs `1+2+3`).
- **Purity Constraints**:
  - No `assert`, `retract`, or global variables (`b_setval`, `nb_setval`).
  - Do not build a string and parse it back to evaluate.
  - Allowed libraries: `lists`, `apply`, `yall`, `aggregate`.
  - Do not print anything.
