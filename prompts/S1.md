1) S1: Binary Tree Traversals (Scheme, file id_q3.rkt)
A binary tree is either the empty list (), or a three-element list (value left right), where left and
right are binary trees. A value is a number or a single-character symbol. Example:
t1 = (4 (2 (1 () ()) (3 () ()))
(6 (5 () ()) (7 () ())))
Conventions
• The height of () is 0, and the height of a node is 1 plus the larger of the heights of its two subtrees. So
a single node has height 1.
• A leaf is a node whose left and right subtrees are both (). The empty tree has no leaves.
• Subtrees are always visited left first, then right.
Tasks. Define three functions. The grader defines the trees and calls them.
• S1.a (print-inorder tree) prints, on one line using display, the list of the values of the tree in
inorder (left subtree, node, right subtree).
Every function ends its output with a newline.
Examples
For t1 above:
• (print-inorder t1) prints (1 2 3 4 5 6 7).
• (print-all-traversals t1) prints the three lines shown below.
• (print-height-and-leaves t1) prints (3 4).
(1 2 3 4 5 6 7)
(4 2 1 3 6 5 7)
(1 3 2 5 7 6 4)
For t2 = (1 () (2 () (3 () ()))): (print-all-traversals t2) prints (1 2 3), (1 2 3) and (3 2
1) on three lines. (print-height-and-leaves t2) prints (3 1).
For t3 = (a (b () ()) (c () ())): (print-all-traversals t3) prints (b a c), (a b c) and (b c
a) on three lines. (print-height-and-leaves t3) prints (2 2).
For the empty tree (): (print-inorder '()) prints (), all three lines of print-all-traversals print (),
and (print-height-and-leaves '()) prints (0 0).
Constraints: the Scheme rules above. Pass all state through function arguments. Prefer tail recursion
where it is natural.
