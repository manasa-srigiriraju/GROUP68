1) P1: Department Assignment Puzzle, Reloaded (Prolog, file id_q1.pl)
Four friends (Alex, Ben, Carla, Dana) each have a department, a favorite language and a project
preference.
• Department: research, development, design, testing
• Favorite language: python, java, c++, javascript
• Project: AI, web, embedded, data

Every friend has a different value for each attribute, so each of the four values of each attribute is used
exactly once.
Clues (numbered; the numbers are used by the tests)
1. The friend who prefers the AI project does not work in research and is not Dana.
2. Alex does not work in development and does not prefer C++.
3. The friend working in the testing department likes Python.
4. Ben prefers web projects and does not work in testing.
5. The friend whose favorite language is Java works in the design department.
6. Carla's project preference is not embedded, and her department is not development.
7. Dana's favorite language is not Java, and she works in research or testing.
8. The friend who prefers data projects works in research and does not use JavaScript.
A solution is a Prolog list of four terms p(Name, Dept, Lang, Project), in the order Alex, Ben, Carla,
Dana. The names are the quoted atoms 'Alex', 'Ben', 'Carla', 'Dana'. The values are exactly these
atoms: research, development, design, testing; python, java, 'c++', javascript; 'AI', web,
embedded, data. Format example only (this is not the answer):
[p('Alex',design,java,web), p('Ben',testing,python,data), ...]
Write each clue as its own clause clue(N, Solution) that succeeds exactly when clue number N holds
in a fully filled-in Solution.
Tasks
P1.a (solve). main/0 prints one solution that satisfies clues 1 to 8, as four lines in exactly this format, in
the order Alex, Ben, Carla, Dana:
Alex = [research, python, AI]
Ben = [development, java, web]
Carla = [design, c++, embedded]
Dana = [testing, javascript, data]
(The four lines above only show the layout; they are not the answer.) Do not hard-code the answer: derive
it from the clues.

SKILL.md in prolog-dev tells you all required info
this solution is into iq_q1.p1
Any relevant tests for P1 should go into tests/p1_test.pl
