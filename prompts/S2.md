1) S2: Conditionally Insert into a Nested List (Scheme, file id_q4.rkt)
The function insert-if-short takes an atom x, a (possibly nested) list lst and an integer n, and inserts
x at the front of every list whose length is less than n, at every level of nesting.
Rules
• The length of a list is the number of its top-level elements (atoms or sublists), measured on the original
list, before any insertion.
• The top-level list is treated like every other list.
• Empty lists are not special: () has length 0, so it becomes (x) whenever 0 < n. This also holds for an
empty top-level list.

• Elements of lst are atoms (digits or symbols) or lists. There are no dotted pairs. The element x is any
atom. n is an integer with n >= 0.
Tasks
• S2.a (print-insert-result) takes no arguments. It reads, with read and in this order, x, lst and n
from standard input. It prints the resulting list with display, followed by a newline. It prints no prompt or
any other text.
Constraints: the Scheme rules above (so length, append, map and the like are forbidden; use your own).
Hidden tests include nesting depth 100 and lists of 10,000 elements.
